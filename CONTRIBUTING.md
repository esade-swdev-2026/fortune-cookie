Contributing to Fortune Cookie

How our group works on this project.
Branches

Never commit straight to main. Start every piece of work on its own branch.
Update main first, then create the branch from it with git switch main, git pull and git switch -c followed by a short name.
Name the branch after what it does, for example add-list-categories, not branch1.
Each person edits different files, so our branches do not conflict.
Commit messages

Start with a capitalised verb in the imperative: Add, Fix, Remove, Update or Rename.
Say what the commit does, so it still makes sense in a month.
If the reason is not obvious, add a blank line and a short explanation.
